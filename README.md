# nanoGPT Phase 2: Instruction SFT, LoRA & DPO Alignment

Implementation of modern LLM training & tuning featuring:
- **Instruction Supervised Fine-Tuning (SFT)** with prompt loss masking
- **Low-Rank Adaptation (LoRA)** (Hu et al., 2021) for parameter-efficient adaptation
- **Direct Preference Optimization (DPO)** (Rafailov et al., 2023) for human alignment

Complies strictly with `core-code-standard.md` (`STD-COD-001` through `STD-COD-009`).
