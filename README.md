# nanoGPT Phase 1: Modern Transformer Architecture

Implementation of modern generative transformer architecture featuring:
- **Rotary Position Embeddings (RoPE)** (Su et al., 2021)
- **Root Mean Square Layer Normalization (RMSNorm)** (Zhang & Sennrich, 2019)
- **Swish Gated Linear Units (SwiGLU)** (Shazeer, 2020)
- **Scaled Dot-Product Attention (SDPA)** with hardware causal fusion

Complies strictly with `core-code-standard.md` (`STD-COD-001` through `STD-COD-009`).
